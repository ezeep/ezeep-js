# 🔝 Top 10 Improvements (Highest Impact First)

1. **Printer config is still merged on the `getAllPrinterProperties` path** *(carried, narrowed)*
   - **Category:** correctness
   - **Why it matters:** The manual switch and the initial load now both replace the config. `printerConfig` (the full list) is still fetched separately and kept as-is; if a response omits capability fields the stale-data question applies there too. Narrower than at the first pass, but unresolved.
   - **Evidence:** `src/components/ezp-printer-selection/ezp-printer-selection.tsx:796-804`
   - **Action:** *Confirm `GetPrinterProperties` always returns every capability field.*

2. **Print settings outlive logout and are shared on a browser profile** *(carried, by ticket design)*
   - **Category:** compliance
   - **Why it matters:** Preferences and the last printer's name persist after sign-out; on a shared machine the next user inherits them for printers they both have. The selection is validated against that user's list, so nothing unusable is preselected.
   - **Evidence:** `src/shared/storage.ts:80-92`
   - **Action:** *Confirm with product/privacy; key the map by user id if unwanted.*

3. **A hoverable tooltip intercepts clicks on what it covers**
   - **Category:** maintainability
   - **Why it matters:** Making the bubble hoverable for WCAG 1.4.13 means it takes pointer events while open, so it can sit over the neighbouring row's remove button. It closes on its own `mouseleave`, so the button is reachable again as soon as the pointer moves off — an accepted trade, but a real one.
   - **Evidence:** `src/components/ezp-file-name/ezp-file-name.scss:70-79`
   - **Action:** *Watch for complaints; a smaller bubble or an offset would reduce the overlap.*

4. **A failed printer list reports "No printers found."**
   - **Category:** documentation
   - **Why it matters:** A network failure and a genuinely empty list reach the same closeable status, so a user with printers may be told they have none.
   - **Evidence:** `src/components/ezp-printer-selection/ezp-printer-selection.tsx:757-763`
   - **Action:** *Add a distinct "could not load printers" string in `en`/`de` if support wants them separated.*

5. **A failed print still rewrites the remembered settings** *(carried)*
   - **Category:** correctness
   - **Evidence:** `src/components/ezp-printer-selection/ezp-printer-selection.tsx:455-480`
   - **Action:** *Decide whether remembering should depend on a successful job.*

6. **`ezp-file-name` reads `ezp-label`'s shadow DOM** *(carried)*

   - **Evidence:** `src/components/ezp-file-name/ezp-file-name.tsx:95-102`

7. **Tooltip placement relies on the consumer setting `position: relative`** *(carried)*
