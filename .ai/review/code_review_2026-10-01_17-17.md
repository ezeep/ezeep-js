# 🔝 Top 10 Improvements (Highest Impact First)

1. **Printer configs are merged, not replaced, when switching printers** *(carried over, unchanged)*
   - **Category:** correctness
   - **Why it matters:** Switching merges the new config over the old, so a field the response omits keeps the previous printer's value; the initial load replaces. Restoration validates saved settings against those arrays.
   - **Evidence:** `src/components/ezp-printer-selection/ezp-printer-selection.tsx:539` vs `:764`
   - **Action:** *Confirm `GetPrinterProperties` always returns every capability field; otherwise replace instead of merging.*

2. **Print settings outlive logout and are shared on a browser profile** *(carried over, by ticket design)*
   - **Category:** compliance
   - **Why it matters:** Preferences and the last printer's name persist after sign-out; on a shared machine the next user inherits them for printers they both have. The selection is still validated against that user's printer list.
   - **Evidence:** `src/shared/storage.ts:80-92`
   - **Action:** *Confirm with product/privacy; key the map by user id if unwanted.*

3. **`setSelectedProperties` has no catch on its own properties fetch** *(new, follow-on from the fix)*
   - **Category:** correctness
   - **Why it matters:** When the user picks a printer by hand, a failed `getPrinterProperties` rejects inside an event handler. It cannot strand the dialog — by then the dialog is interactive — but it surfaces as an unhandled rejection and leaves the selection showing a printer whose config never loaded, the exact state the load path now avoids.
   - **Evidence:** `src/components/ezp-printer-selection/ezp-printer-selection.tsx:534-548`
   - **Action:** *Reuse `loadSelectedPrinterConfig()` for the manual path so both behave the same.*

4. **A failed printer list reports "No printers found."** *(new)*
   - **Category:** documentation
   - **Why it matters:** A network failure and an empty list now reach the same closeable status, so a user with printers may be told they have none. Reuses existing copy rather than adding strings.
   - **Evidence:** `src/components/ezp-printer-selection/ezp-printer-selection.tsx:752-758`
   - **Action:** *Add a distinct "could not load printers" message in `en`/`de` if support wants the two cases separated.*

5. **A failed print still rewrites the remembered settings** *(carried over)*
   - **Category:** correctness
   - **Evidence:** `src/components/ezp-printer-selection/ezp-printer-selection.tsx:455-480`
   - **Action:** *Decide whether remembering should depend on a successful job.*

6. **`ezp-file-name` reads `ezp-label`'s shadow DOM** *(carried over)*
